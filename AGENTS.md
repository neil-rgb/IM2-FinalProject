# B-TRACK project guidance

## UI and UX

- Use the installed `stark` skill for B-TRACK interface design, review, and implementation. Route through its UX and web-design guidance before changing a screen.
- Preserve the established visual language: industrial monospace typography, a four-size type scale, warm off-white/beige paper surfaces, deep navy ink and folder accents, and the barangay records cabinet/archive metaphor.
- Keep document folders solid navy without texture. Keep controls in their existing toolbars; do not add buttons to folder faces or introduce decorative borders and shadows.
- Prioritize compact, readable record scanning, clear status and date labels, responsive layouts, keyboard focus, and reduced-motion behavior.
- Keep the existing PHP, CSS, JavaScript, and MySQL stack. Prefer existing CSS tokens and patterns; avoid adding dependencies for visual-only changes.
- Preserve project rules: the secretary is the system user, processing-history records are immutable, and status changes require confirmation.
